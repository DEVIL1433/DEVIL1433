## 👁️ Featured project — CredLens

[**CredLens**](https://github.com/DEVIL1433/credlens) — a passive
**network credential-leak detector** for **Windows, Linux, and Android**
that surfaces leaked logins, session cookies, API keys, bearer tokens,
and NTLM hashes with the device that leaked them and the site they went
to. VPN capture on any phone (IPv4 + IPv6), rooted hotspot watch, LAN
scan, session reports, and a device identity engine that names devices
from DHCP, User-Agent, and maker traffic.

📱 **[Download the Android app (v1.6)](https://github.com/DEVIL1433/credlens/releases/tag/v1.6)**
